# Living Streets

An interactive information session on funding nature-based solutions for climate-ready Jamaican towns (J-USE Call 2 Site Explorer, Environmental Foundation of Jamaica).

## Run it

It's a single self-contained page — open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages). It loads three.js and fonts from public CDNs, so it needs an internet connection.
